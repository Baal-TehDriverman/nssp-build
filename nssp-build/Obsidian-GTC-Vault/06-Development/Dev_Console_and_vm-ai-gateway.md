## Purpose

Two linked workstreams under `/home/tehlappy/Dev Console/`:

### 1. Developer Dashboard (`devdashboard/`)
Interactive GitHub portfolio explorer + Gemini AI code analyst for `Baal-TehDriverman`.
- **Frontend:** React 19 + Vite + Tailwind v4 (SPA in `dist/`)
- **Backend:** Express + Vite middleware (`server/index.ts`); production mode serves `dist/`
- **Endpoints:** `/api/github/user/:u`, `/api/github/user/:u/repos`, `/api/gemini/analyze-profile`, `/api/gemini/chat`
- **Launch:** `/home/tehlappy/Desktop/Developer Dashboard.desktop` → `launch-standalone.sh`
- **Token policy:** GitHub auth via `GITHUB_PAT`/`GITHUB_TOKEN` env (no hardcoded fallback). Gemini via `GEMINI_API_KEY`.

### 2. VM AI Gateway (`vm-ai-gateway/`)
FastAPI control plane for apps, libvirt VMs, and system status (separate from the deployed copy at `_shared/gateway/`).
- **Entrypoint:** `lilith-gateway/gateway_server.py` (the `gateway-server.py` legacy duplicate was removed)
- **Endpoints:** `/api/status`, `/api/apps`, `/api/vms/{action}/{name}`, `/v1/chat/completions` (Ollama proxy)
- **Knowledge graph:** `.ua/knowledge-graph.json` (167 nodes / 246 edges, generated by Understand-Anything)
